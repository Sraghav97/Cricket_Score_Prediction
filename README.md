# 🏏 Cricket Score Prediction

Predict the **first innings score** of a T20 cricket match using **machine learning**.

---

## 📌 Overview

This project uses historical T20 match data and machine learning algorithms to predict the first innings score.  
It helps **teams, analysts, and cricket enthusiasts** strategize and understand match dynamics.

---

## ⚙️ Features

- **Data Preprocessing**: Clean and prepare match data for modeling.  
- **Model Training**: Train machine learning models to predict scores.  
- **Prediction Interface**: Input match details and get instant score predictions.

## 📊 Example Prediction

Enter match details such as:

- **Batting Team**  
- **Bowling Team**  
- **Venue**  
- **Current Score & Overs**

The application will predict the **first innings score**.

💡 **Tip**: The prediction updates in real-time as you input match details.

---

## 📈 Dataset

The model uses historical T20 match data with the following features:

| Feature      | Description                        |
|--------------|------------------------------------|
| bat_team     | Batting team name                  |
| bowl_team    | Bowling team name                  |
| venue        | Match venue                        |
| runs         | Runs scored at various stages      |
| wickets      | Wickets fallen at various stages   |
| overs        | Overs completed at various stages  |
